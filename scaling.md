Technical Specification: Symmer-PySCF Quantum Hamiltonian Database Generation1. Project ObjectiveThe goal is to build an automated pipeline using PySCF, OpenFermion, and Symmer to generate a database of molecular Hamiltonians. This database is specifically designed to stress-test quantum computing (QC) algorithms by benchmarking their ability to handle static correlation (multi-reference character).To achieve this, the dataset will consist of uniform bond-scaling trajectories (from equilibrium to dissociation) for various molecules, providing a classical baseline (Hartree-Fock) and a ground-truth target (Full CI) for the quantum algorithms to solve.2. Technology Stack & PipelineElectronic Structure: PySCF (Generates molecular integrals and solves HF/FCI).Fermionic/Qubit Mapping: OpenFermion (specifically openfermionpyscf and MolecularData).Pauli Operator Representation: Symmer (Converts to PauliwordOp for efficient subspace methods and QC tracking).3. Methodology: The "Locked Spin" Uniform Scaling StrategyTo guarantee a rigorously difficult mathematical problem for QC benchmarking, the pipeline will strictly employ the Locked Spin Strategy.Geometry: Uniformly scale all atomic coordinates by a single scaling factor $\alpha$.Spin: Enforce a fixed spin state (e.g., $S=0$ singlet) defined at the equilibrium geometry, and lock it for the entire dissociation curve.Crucial Context for AI: Do not attempt to dynamically search for the lowest physical spin state (e.g., crossing over to a triplet at large distances). The objective is to define a strict mathematical Hamiltonian for the specified spin symmetry, regardless of whether it represents the true physical ground state of the vacuum fragments.4. Required Deliverables per Data PointFor every scaling factor $\alpha$, the pipeline must extract and document the following into the database:Geometry: The scaled Cartesian coordinates.Basis Set: e.g., STO-3G.Spin: The locked multiplicity.HF Energy: The classical baseline.FCI Energy: The exact ground-truth target for the quantum algorithm.Symmer Pauli Hamiltonian: The PauliwordOp object containing the Pauli strings and coefficients.FCI State Vector: The exact ground state wavefunction of the generated Hamiltonian.5. Known Pitfalls & Handled Edge CasesWhen scripting the automated pipeline, the following quantum chemistry edge cases must be accommodated:A. Hartree-Fock Non-Convergence at DissociationThe Issue: Standard Restricted Hartree-Fock (RHF) will inevitably fail to converge (hit max_cycle) at large stretching distances due to immense static correlation.The Handling: A failed HF calculation does not mean a failed Hamiltonian. If PySCF's SCF cycle fails to converge, the script must catch the warning but proceed normally. The pipeline will extract the unconverged molecular orbital coefficients (mo_coeff). OpenFermion and Symmer will successfully map these into a mathematically valid Pauli Hamiltonian. For QC benchmarking, this extremely poor HF reference state is a highly desirable feature.B. The Spin Crossover / Excited State IllusionThe Issue: Because we are locking the spin (e.g., to a singlet), the calculated state at large distances might actually be an excited state of the separated physical fragments (if the true ground state crossed over to a triplet).The Handling: Ignore the physical crossover. The FCI solver must simply target the lowest eigenvalue of the specific Hamiltonian generated. Even if it represents a physical excited state of the atoms, it is the exact mathematical ground state of the singlet Hamiltonian we are feeding to the QC algorithm.C. Open-Shell Systems (ROHF vs. UHF)The Issue: If a molecule has an open-shell equilibrium state (e.g., a doublet radical or $O_2$ triplet), PySCF defaults to Unrestricted Hartree-Fock (UHF). UHF utilizes different spatial orbitals for alpha and beta electrons, which breaks the strict spatial-orbital assumptions required for standard qubit mappings (like Jordan-Wigner).The Handling: openfermionpyscf's internal run_pyscf driver natively handles this. If the user-defined multiplicity is greater than 1, the pipeline automatically intercepts PySCF and forces it to use Restricted Open-Shell Hartree-Fock (ROHF). This guarantees the spatial orbital pairing is maintained, preventing spin-contaminated Pauli strings. No manual patching of the SCF method is required if using the standard MolecularData flow.

6. Determining the Dissociation Limit (Maximum Scaling Factor $\alpha$)When generating the uniform scaling trajectories, the script must systematically determine at what maximum scaling factor ($\alpha_{max}$) the molecule is considered "fully dissociated" to cap the dataset efficiently.The Phenomenological Rule of ThumbFor standard small molecules and covalent bonds (e.g., C-C, C-H, N-N), an $\alpha_{max}$ between 2.5 and 3.0 is almost universally sufficient.Equilibrium bond lengths ($\alpha = 1.0$) are typically between 1.0 Å and 1.5 Å.Scaling by $3.0$ pushes the internuclear distances to 3.0 Å – 4.5 Å.At these distances, spatial orbital overlap is effectively zero, the exchange interaction vanishes, and the multi-reference character (static correlation) reaches its absolute maximum. Extending the grid further provides no additional mathematical challenge for the quantum solver.The Mathematical Convergence Criteria (Recommended Automation)To prevent hardcoding an arbitrary limit that might waste compute time or undershoot larger molecules, implement a gradient-based stopping condition in your automated pipeline.Calculate the Energy Gradient: At each sequential scaling step $\alpha_i$, calculate the change in the exact energy: $\Delta E = |E_{FCI}(\alpha_i) - E_{FCI}(\alpha_{i-1})|$.Apply a Threshold: Once $\Delta E$ drops below a strict chemical accuracy threshold (e.g., $< 10^{-4}$ Hartree per $0.1$ step in $\alpha$), the potential energy curve has flattened into the asymptotic dissociation limit.Terminate: Halt the geometry scan for that molecule.Grid Spacing StrategyA simple linear grid (e.g., np.linspace(0.5, 3.0, 50)) is the easiest to implement, but an adaptive grid provides much better data density for quantum algorithm developers:High-Density Grid ($\Delta\alpha \approx 0.05$): Focus the finest sampling between $\alpha = 0.8$ and $\alpha = 2.0$. This is the critical transition zone. It captures the steep repulsive wall, the equilibrium well, and the exact avoided crossing/bond-breaking region where Hartree-Fock oscillations occur and classical methods struggle the most.Low-Density Grid ($\Delta\alpha \approx 0.25$): For $\alpha > 2.0$. Once the bond is broken and the wavefunctions are strictly localized on the dissociated fragments, the energy curve flattens out. High-density sampling here wastes your classical pipeline compute time without providing any new optimization challenge to the downstream quantum algorithm.
